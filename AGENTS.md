# AGENTS.md

## Source of truth

- `skills/<name>/` contains each authored skill workflow.
- `catalog.json` owns each skill's independent semantic version at `skills.<name>.version`. Bump only the skills whose published payload changes.
- `plugins/`, `.claude-plugin/marketplace.json`, `.agents/plugins/marketplace.json`, and `platforms/openclaw/` are generated by `scripts/build.sh`.
- Never edit generated files directly. Change the source skill or `catalog.json`, then rebuild.
- `dist/` contains reproducible release artifacts and is not committed.
- Releases use `<skill>-v<version>` tags and publish only that skill's archives, checksums, and optional ClawHub payload. Legacy `v*` tags remain historical snapshots.

## Verification

- Run `./scripts/validate.sh` before committing.
- Inspect staged and unstaged changes before every commit and stage only files for the current change.

## Git

- Commit messages use `{type}: {message}` with a lowercase concise type and an imperative, specific message.
